# COBRA FX — Complete multi-page front-end

COBRA FX is a responsive multi-page trading-tools website based on the visual
direction in the supplied Tredakit screenshots, with original COBRA FX branding
and copy.

## Pages
Home, Free Bots, Bot Builder, Analysis, Manual Trader, Copy Trader, Live Charts,
Tutorials, Guides, FAQ, Login, Signup, Dashboard and Settings.

## Files
- HTML pages
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- robots.txt
- DEPLOYMENT.md

This package is deployable as a static website. Financial execution, live market
feeds, authentication, payments and other server-side integrations must be wired
to real services before production use.
